# Contributing to Cypress Generic Library

A detailed **code structure guide** and explanation of **how the library works** will be added in the `docs` folder soon.

---

## How to Contribute

1. **Fork the repository**

2. **Clone your fork locally**

   ```bash
   git clone https://github.com/YassineOuhadi/cypress-generic-package.git
   ```

3. **Create a new branch**

   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make your changes**

   * Follow the existing code style.
   * Add comments and documentation where necessary.
   * If adding new features, ensure there are example usage or tests.
   * Make sure your changes don’t break existing functionality.


6. **Commit your changes**

   ```bash
   git add .
   git commit -m "Add feature XYZ / Fix bug ABC"
   git push origin feature/your-feature-name
   ```

7. **Open a Pull Request**
---

Thank you for helping make this library better!
